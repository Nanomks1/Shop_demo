# محلنا — خريطة المشروع (مجلد v2)

| الملف | محتواه |
|---|---|
| index.html | الصفحة، تحمّل 3 سكربتات بهذا الترتيب: core ثم base ثم features |
| core.js | الأساس: التخزين، الشاشات، النوافذ، المستخدمون، الوسوم، النسخ الاحتياطي |
| base.js | الهواتف، الأنتي كاس، البوشيط، الإكسسوارات، الصيانة، الجرد اليومي، الحدود |
| features.js | التحسينات فوق base: الألوان والترتيب، مستويات الأنتي كاس، دليل الأسعار، القفل والباركود، التقرير، الخانات المخصصة، تقسيم الإعدادات |
| style.css | التنسيق |
| manifest.json, sw.js, icon-*.png | تثبيت التطبيق على الهاتف |

**قواعد:**
- الترتيب مهم: كل جزء في features.js يعدّل ما قبله، لذلك لا تغيّر ترتيب الأقسام داخل الملف.
- كل قسم في الملفين يبدأ بتعليق عريض يشرح محتواه.
- الميزة الجديدة تُضاف في آخر features.js، والمزامنة ستكون ملفاً رابعاً sync.js بعده.
