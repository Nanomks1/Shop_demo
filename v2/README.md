# محل عزيز — خريطة المشروع (مجلد v2)

| الملف | محتواه |
|---|---|
| index.html | الصفحة، تحمّل السكربتات بهذا الترتيب: core ← base ← features ← sync ← groups ← tidy |
| core.js | الأساس: التخزين، الشاشات، النوافذ، المستخدمون، الوسوم، النسخ الاحتياطي، تجزئة الرموز السرية (hs / hv) |
| base.js | الهواتف، الأنتي كاس، البوشيط، الإكسسوارات، الصيانة، الجرد اليومي، الحدود |
| features.js | التحسينات فوق base: الألوان والترتيب، مستويات الأنتي كاس، دليل الأسعار، القفل والباركود، الأمان، الخانات المخصصة |
| sync.js | المزامنة بين الأجهزة (Supabase) وتشفير بيانات الزبائن |
| groups.js | مجموعات الكابلات والشواحن + رمز كل موظف |
| tidy.js | شاشة التقرير وإعداداته (عنوان، ما يُدرج، المستوى، الأقسام) + ترتيب شاشة «المزيد» في أقسام |
| style.css | التنسيق |
| manifest.json, sw.js, icon-*.png | تثبيت التطبيق على الهاتف والعمل بدون إنترنت |

**قواعد:**
- الترتيب مهم: كل ملف يعدّل ما قبله، فلا تغيّر ترتيب السكربتات في index.html.
- الميزة الجديدة تُضاف في ملف جديد يُحمَّل آخراً، أو في آخر الملف الأخير.
- عند إضافة ملف جديد: أضفه في index.html وفي قائمة ASSETS داخل sw.js وارفع رقم CACHE.
- قبل رفع أي ملف تأكد أن أول سطر فيه هو تعليقه الصحيح (لا تلصق css داخل js).
