# محل عزيز — مجلد v3

بيانات v3 هي نفس بيانات v2 (نفس مفتاح التخزين والرموز السرية).

| الملف | محتواه |
|---|---|
| core.js | الأساس: الحالة، الحفظ، الصور، الرموز السرية، النوافذ، الرجوع، التراجع والحذف، أدوات عامة (`dg` أرقام، `waNum` رقم واتساب، البحث الموحّد) |
| icons.js | الأيقونات الملونة (CI) |
| topup.js | قسم التعبئة (3 هواتف لكل مشغّل + بطاقات 5/10/20/50) |
| inventory.js | الهواتف، الأنتي كاس، البوشيط، الإكسسوارات، المجموعات، الحجز، IMEI والباركود |
| invtools.js | أدوات المخزون: الجولة اليومية، الوسوم، الألوان، حقول الإكسسوارات، الإعدادات |
| repair.js | الصيانة: استلام وتسليم، موعد التسليم، ضمان، IMEI، صور، واتساب، دليل الأسعار، طلبات الزبائن |
| report.js | التقرير اليومي ونص الواتساب |
| sync.js | المزامنة (Supabase) مع تشفير بيانات الزبائن |
| extra.js | المستعمل، الديون، الإحصائيات، البيع السريع، ملحقات التسليم |
| app.js | الرئيسية، البحث، المزيد، المستخدمون، القفل، النسخ الاحتياطي، الإقلاع |
| style.css, index.html, sw.js, manifest.json | الواجهة والتثبيت |

**القاعدة:** لا ملف يعدّل دوال ملف آخر؛ كل ملف يسجّل نفسه في سجلات `core.js`: `VW` `HK` `HOME` `MORE` `SRCH` `LM`.

**عند إضافة ملف:** أضفه في index.html (قبل app.js) وفي ASSETS داخل sw.js، وارفع رقم الإصدار في index.html وsw.js معاً (فحص GitHub يتحقق).
