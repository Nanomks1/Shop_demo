# محل عزيز — مجلد v3

بيانات v3 هي نفس بيانات v2 (نفس مفتاح التخزين والرموز السرية).

| الملف | محتواه |
|---|---|
| core.js | الأساس: الحالة، الحفظ، الصور، الرموز السرية، النوافذ، الرجوع، التراجع والحذف، أدوات عامة (`dg` أرقام، `waNum` رقم واتساب، البحث الموحّد) |
| icons.js | الأيقونات الملوّنة (CI) والأيقونات الإضافية |
| topup.js | قسم التعبئة (3 هواتف لكل مشغّل + بطاقات 5/10/20/50) |
| invbase.js | أساس المخزون: مساعدات، العرض المضغوط، الحجز، الألوان والفلترة، الحقول والخانات المخصصة |
| invphones.js | الهواتف: بطاقة، إضافة، اقتراح الملحقات، حجز، سجل الحركات |
| invglass.js | الأنتي كاس: مجموعات الموديلات والمستويات |
| invpochette.js | البوشيط: رجالي/نسائي، ألوان وتصاميم |
| invacc.js | الإكسسوارات ومجموعات الكابلات والشواحن |
| invreport.js | الشراء، سطور تقرير المخزون (`invLines`)، البحث الموحّد وعرض القسم |
| invround.js | الجولة اليومية (الجرد) وكاشف الأثمنة |
| barcode.js | الباركود و IMEI والبيع السريع |
| invset.js | إعدادات المخزون: الخانات، الحدود، الألوان، أنواع الإكسسوار، إدارة الوسوم |
| repair.js | الصيانة: استلام وتسليم، موعد التسليم، ضمان، IMEI، صور، واتساب، دليل الأسعار، طلبات الزبائن |
| report.js | التقرير اليومي ونص الواتساب |
| sync.js | المزامنة (Supabase) مع تشفير بيانات الزبائن |
| extra.js | المستعمل، الديون، الإحصائيات، البيع السريع، ملحقات التسليم |
| home.js | الرئيسية، البحث، المزيد والإعدادات، الأيقونة العائمة |
| users.js | المستخدمون والصلاحيات، تسجيل الدخول والقفل |
| backup.js | النسخ الاحتياطي والاستعادة والنسخ التلقائي |
| app.js | الإقلاع فقط (آخر ملف) |
| style.css, index.html, sw.js, manifest.json | الواجهة والتثبيت (كل الأنماط في style.css) |

**القاعدة:** لا ملف يعدّل دوال ملف آخر؛ كل ملف يسجّل نفسه في سجلات `core.js`: `VW` `HK` `HOME` `MORE` `SRCH` `LM`.

**عند إضافة ملف:** أضفه في index.html (قبل app.js، وبالترتيب نفسه) وفي ASSETS داخل sw.js، وارفع رقم الإصدار في index.html وsw.js معاً (فحص GitHub يتحقق).
