# محل عزيز — مجلد v3 (النسخة المنظَّفة)

بيانات v3 هي نفس بيانات v2 تماماً (نفس مفتاح التخزين والرموز السرية)، فلا يضيع شيء.

| الملف | محتواه | الحالة |
|---|---|---|
| core.js | الأساس: الحالة، الحفظ، خزنة الصور، الرموز السرية، النوافذ، زر الرجوع، التراجع والحذف | ✅ المرحلة 1 |
| app.js | الرئيسية، البحث الموحّد، المزيد، المستخدمون، القفل، النسخ الاحتياطي، الإقلاع | ✅ المرحلة 1 |
| inventory.js | الهواتف، الأنتي كاس، البوشيط، الإكسسوارات، المجموعات، الحجز، IMEI والباركود، الجولة اليومية، إعدادات المخزون | ✅ المرحلة 2 |
| repair.js | الصيانة: استلام وتسليم، الضمان، IMEI، الصور، واتساب، دليل الأسعار، طلبات الزبائن | ✅ المرحلة 3 |
| report.js | التقرير اليومي ونص الواتساب وإعداداته | ✅ المرحلة 4 |
| sync.js | المزامنة بين الأجهزة (Supabase) مع تشفير بيانات الزبائن | ✅ المرحلة 4 |
| style.css, index.html, sw.js, manifest.json, icon-*.png | الواجهة والتثبيت | ✅ |

**القاعدة الجديدة:** لا ملف يعدّل دوال ملف آخر. كل ملف يسجّل نفسه في سجلات `core.js`:
`VW` (الشاشات) · `HK` (خطّافات الحفظ) · `HOME` (أزرار الرئيسية) · `MORE` (قائمة المزيد) · `SRCH` (مصادر البحث) · `LM` (الحدود).

عند إضافة ملف: أضفه في index.html (قبل app.js) وفي ASSETS داخل sw.js وارفع رقم CACHE.
